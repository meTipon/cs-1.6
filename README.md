# داستلي — موقع ثابت (بدون أدوات بناء)

## الرفع
ارفع كل الملفات والمجلدات على GitHub، ثم في Vercel: Add New → Project → اختر الريبو → Deploy.

## الإعدادات (ملف site.js، أول الملف)
- `name` اسم الموقع
- `downloadUrl` رابط التحميل
- `discordInvite` رابط دعوة الديسكورد

## رسالة الديسكورد
في أعلى كل ملف `.html` قسم "رسالة الديسكورد": عدّل og:title وog:description وtheme-color.
أهم صفحة هي index.html (الرابط الرئيسي). ديسكورد يحفظ نسخة قديمة، فبعد التعديل أضف `?v=2` للرابط.

## ملف اللعبة
حط الملف في مجلد download باسم cs16.zip، وأي زر تحميل في الموقع يحمّله مباشرة.
لو الملف كبير (أكثر من 100MB) استخدم GitHub Releases وحط رابطه في downloadUrl.

## الصور
حط صورك في مجلد images (مثلاً images/hero.jpg) وتظهر في الرئيسية تلقائي.
